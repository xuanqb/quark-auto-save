# 夸克分享链接一次性转存

把用户发来的夸克分享链接原样存进自己的网盘，落到 `/默认根目录/<分享标题>/`。

## 前提

- 宿主机（Hermes 运行处）能执行 `docker` 命令
- quark-auto-save 容器正在运行，且容器内 `config/quark_config.json` 已配好 cookie
- 容器名默认自动探测；探测不到时用环境变量 `QUARK_CONTAINER` 指定

## 执行步骤

1. 从用户消息中提取分享链接，形如 `https://pan.quark.cn/s/xxxxxxxx`。
   - 链接带 `#/list/share/...` 片段时，只转存该子目录
   - 用户另给提取码时，拼到链接后：`https://pan.quark.cn/s/xxxxxxxx?pwd=提取码`
2. 调用脚本（skill 目录下的 scripts）：

```bash
bash scripts/quark_save.sh '<分享链接>'
```

3. 读脚本输出的最后一行「结果：」，据此回报用户：

| 脚本输出 | 回报内容 |
|---|---|
| `结果：转存成功` | 已存到脚本输出的「目标目录」 |
| `结果：目标目录已存在同名文件，本次未新增（未重复转存）` | 该分享之前已存过，未重复转存 |
| `结果：失败，<原因>` | 把「失败，」后面的原因转述给用户（常见：分享失效、cookie 过期、容器未运行） |

汇报时带上「账号」和「目标目录」两行，便于用户确认存到了哪个账号、哪个目录。

## 配置项

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `QUARK_SAVE_ROOT` | `/Hermes转存` | 转存根目录，分享标题作为其子目录 |
| `QUARK_CONTAINER` | 自动探测 | quark-auto-save 容器名 |
| `QUARK_SAVE_TIMEOUT` | `1800` | 秒。整个转存的超时上限，超时会被强制中断 |

## 行为说明

- **保持原名**：不重命名、不做文件名整理，文件按分享里的原始名称存进去。
- **一次性**：在容器内直接调用转存逻辑，不生成任何配置文件，不改动正式配置，不写入 tasklist，不参与定时追更。
- **自动建目录**：`/默认根目录/<分享标题>` 不存在时自动创建。标题中的 `/\:*?"<>|` 会被替换为 `_`。
- **去重**：目标目录已有同名文件时跳过，不会重复转存。
- **超时保护**：默认 30 分钟强制中断，避免夸克接口无响应时永久挂住。
- **cookie 安全**：只在容器进程内存中使用，不写入磁盘。
- **不做的事**：不签到、不刷新 Emby 媒体库、不触发 alist/strm 生成、不发外部推送通知，结果由脚本输出交给你回报。

## 大分享的性能

转存耗时随文件数量增长，且全部请求串行：每 50 个文件一轮分页列举，轮询云侧任务每 0.5 秒一次。几百个文件通常几分钟内完成；上千个文件可能需要十几分钟，接近超时上限时应调大 `QUARK_SAVE_TIMEOUT`。
